# IBM Bob session reports

Export the session report from IBM Bob after each task in `docs/bob-tasks/` and save it here, one file per task:

```
bob_sessions/
  01-python-repo.<ext>
  02-tests.<ext>
  03-orchestrate-agent.<ext>
  ...
```

Keep the reports exactly as Bob exports them. Note the credits each task used in `docs/bob-tasks/credit-log.md`.
