### FIXED
| ID | What was fixed |

| S2 | `.env` confirmed in `.gitignore` (line 2) — token will never be committed |

### NOT APPLICABLE
- `eval()` — zero occurrences in all files
- `exec()` Python — zero occurrences
- `subprocess(shell=True)` — zero occurrences
- `document.write()` — zero occurrences
- `postMessage("*")` — zero occurrences
- `Math.random()` for security — zero occurrences
- API key leakage: `WATSONX_API_KEY`, `SF511_API_KEY`, `NREL_API_KEY`, `OPENEI_API_KEY` are only passed
  to upstream HTTP requests via `os.getenv()`; they never appear in any `self.reply()` call

- XSS in HTML pages: all server-sourced strings (`customer`, `message`, `vehicle`, `text`,
  `headline`, `name`) are wrapped with `esc()` from `common.js` line 12

## How to load the token for the running server

PowerShell (load .env then restart):
```powershell
Get-Content .env | ForEach-Object {
  if ($_ -notmatch '^#' -and $_ -match '=') {
    $k,$v = $_ -split '=',2
    [System.Environment]::SetEnvironmentVariable($k.Trim(), $v.Trim())
  }
}
python server.py 8000
```

The token value is in `.env` (not committed). Share it with the team via a secure channel
(e.g. the IBM SkillsBuild team Slack or a password manager).
